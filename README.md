## このページを使った動作確認の手順

1. 管理画面（`/#/admin`）→「URL管理」を開く
2. 「新規登録」から、下の raw URL を登録する

   ```
   https://raw.githubusercontent.com/Kazuhiro-matsui-estyle/url-update-check-demo/main/README.md
   ```

3. 「今すぐ更新チェック」を実行する → 「更新」列のボタンはグレーのまま（更新なし）
4. このファイルを GitHub 上で編集して commit する（下の更新履歴に1行足すのが分かりやすい）
5. **5分ほど待ってから**「今すぐ更新チェック」を再実行する → ボタンが緑になり押せる状態になる（更新あり）

週次の自動チェック（毎週日曜 03:00 JST）でも同じ判定が行われます。

### 補足

- 更新の判定は、取得した本文のハッシュと、システムに取り込み済みの本文のハッシュを比較して行われます
- 「更新あり」のフラグは、管理画面から再取得するまで立ったままになります
- 「更新」列のボタンは、ラベルが常に「更新あり」と表示されます。グレーで押せない状態が「更新なし」、緑で押せる状態が「更新あり」です
- raw.githubusercontent.com は最大5分間キャッシュされるため、編集直後のチェックでは反映されないことがあります
